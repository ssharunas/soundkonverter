# soundKonverter
soundKonverter is a frontend to various audio converters.

This is a Qt6 port. Plugin 'libav' was removed, because libav is dead.
Currently all other codec converters, replay gain, CD ripper and filter plugins are ported.
Some modal windows are still buggy and need correction💢.
Command line arguments are not yet ported.

![Screen shot of soundKonverter](soundkonverter.png)

The key features are:
- Audio conversion
- Replay Gain calculation
- CD ripping

See the [wiki](https://github.com/HessiJames/soundkonverter/wiki) for more information.
